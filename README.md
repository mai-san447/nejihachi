# ネジハチの もり

歯車のミツバチ「ネジハチ」の絵本シリーズ（さく・え えむこ）と、SUZURIのグッズを紹介するページ。

- 公開先：https://emko.work/nejihachi/ （GitHub Pages）
- 中身：日本語 `index.html`、英語 `en/index.html`、共通の `style.css`、画像 `img/`（英語版の表紙・中のページは `en/img/`）。ビルドは要らない
- 画像：絵本の表紙・キャラクターシートから切り出し、Web用に縮小したもの。元の画像は OneDrive の `執筆\絵本\` にある

## 更新するとき
- 新しい巻が発売されたら、「シリーズの ほかの本」の「準備中」を「発売中」にして、Amazonのボタンをつける（日本語は amazon.co.jp、英語は amazon.com）
- 英語版が出た巻は、`en/index.html` の「More in the series」に足す
- 見た目を変えるときは `style.css` を直す（日本語・英語の両方に効く）
