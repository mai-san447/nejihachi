# ネジハチの もり

歯車のミツバチ「ネジハチ」の絵本シリーズ（さく・え えむこ）と、SUZURIのグッズを紹介するページ。

- 公開先：https://emko.work/nejihachi/ （GitHub Pages）
- 中身：`index.html` 1枚と `img/` だけ。ビルドは要らない
- 画像：絵本の表紙・キャラクターシートから切り出し、Web用に縮小したもの。元の画像は OneDrive の `執筆\絵本\` にある

## 更新するとき
- 1冊目がAmazonで発売されたら、「Amazonで発売準備中」のボタンを商品ページへのリンクに変え、1冊目の「まもなく発売」を「発売中」にする
- 4・5冊目の表紙ができたら `img/` に足して、`cover blank` の枠と入れかえる
